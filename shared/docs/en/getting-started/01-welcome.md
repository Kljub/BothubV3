BotHub is a self-hosted dashboard for your own Discord bots. You bring the bot (a Discord application with a token); BotHub runs it and gives it modules, commands and plugins that you switch on and set up in the browser. No code needed.

## The parts of the dashboard

| Area | What it is for |
|---|---|
| **Bot switch** (top left) | Your bots. The selected bot decides what the bot pages show. |
| **Overview** | Usage of the bot: new members, active users, messages, voice minutes, moderation, commands, plugins. Filter by server and time range. |
| **Settings** | Name, token, start/stop/restart, delete the bot. |
| **Invite Bot** | The invite link of the bot for your servers. |
| **Status** | Online status, activity ("Playing …"), custom status, rotation, profile. |
| **Server** | The servers the bot is in. |
| **Logs** | What the bot did and what went wrong. |
| **Modules** | Ready-made features: moderation, tickets, leveling, economy, welcome messages and many more. |
| **Plugins** | Extra features from the App Store. |
| **Docs** | This documentation. |

The **user menu** (bottom left) opens your settings, the App Store and the admin area. **Start Tour** (top right) walks you through the dashboard.
